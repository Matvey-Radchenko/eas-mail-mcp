# Инструкция для ИИ-агента

Этот архив устанавливает локальный EAS Mail MCP на macOS 14 или новее. Он
содержит бинарники для Apple Silicon и Intel; `install.sh` сам выбирает вариант
по архитектуре текущего Mac.

## Границы безопасности

- Работайте с локальным путём к скачанному архиву. Не загружайте архив, бинарники
  или diagnostics во внешние сервисы.
- Не просите пользователя отправлять пароль в чат, файл или аргумент команды.
  Пароль вводится пользователем только в закрытом интерактивном prompt.
- Не используйте `--password-stdin`, не читайте macOS Keychain и не отключайте
  TLS, проверку сертификатов или quarantine без явного подтверждения пользователя.
- Не включайте write tools. Они настраиваются отдельно после read-only проверки.

## Установка

1. Распакуйте архив в новую временную директорию и перейдите в неё.
2. Убедитесь, что присутствуют `SHA256SUMS`, `TARGET_ARCHS`, `install.sh` и
   `BUILD-METADATA.json`.
3. Проверьте содержимое bundle:

   ```bash
   shasum -a 256 -c SHA256SUMS
   cat BUILD-METADATA.json
   ```

4. Запустите установщик:

   ```bash
   ./install.sh
   ```

   Если macOS quarantine блокирует неинтерактивный запуск, сообщите об этом
   пользователю. Только после его подтверждения повторите:

   ```bash
   ./install.sh --remove-quarantine
   ```

5. Импортируйте предоставленный оператором профиль, если он лежит рядом с
   архивом, затем запустите мастер:

   ```bash
   ~/.local/bin/eas-mail-mcp profile import ./team-profile.toml
   ~/.local/bin/eas-mail-mcp setup
   ```

   Профиль не содержит credentials, но может содержать непубличные endpoint
   metadata. Не загружайте его во внешние сервисы. Передайте интерактивный
   terminal пользователю на время ввода email, username и пароля. Повторите
   `account add`, если нужно добавить второй аккаунт.

6. Настройте только тот MCP-клиент, из которого выполняется установка:

   ```bash
   ~/.local/bin/eas-mail-mcp client configure codex
   ~/.local/bin/eas-mail-mcp client configure claude
   ~/.local/bin/eas-mail-mcp client configure opencode
   ```

   Выберите одну подходящую команду. Неизвестную или неподдерживаемую версию
   клиента не обходите: сохраните ошибку без чувствительных данных и сообщите её
   пользователю.

7. Выполните read-only диагностику:

   ```bash
   ~/.local/bin/eas-mail-mcp account list
   ~/.local/bin/eas-mail-mcp doctor
   ```

8. Попросите пользователя перезапустить MCP-клиент. После перезапуска проверьте
   `accounts_list`, `folders_list` и один ограниченный `mail_list` без мутаций.

Установка завершена только после успешного `doctor`, подключения текущего
клиента и read-only MCP-вызова. Сетевые ошибки не исправляйте ослаблением TLS;
сначала попросите пользователя проверить требуемую корпоративную сеть или VPN.
