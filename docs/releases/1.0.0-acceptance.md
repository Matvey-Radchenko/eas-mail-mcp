## Scope

The release includes the mail, scheduling, diagnostics, and recovery work listed
in [CHANGELOG.md](../../CHANGELOG.md). It preserves the EAS 14.1 security boundary,
bounded content retrieval, per-account write opt-in, and UUID idempotency.
The agreed live scope includes synthetic service messages to the owner's own
accounts and dedicated calendar fixtures. OOF changes require a separate
authorized test window because they affect replies to other incoming mail.
