# 0.5.0 release acceptance

- Status: release candidate
- Release type: stable feature release
- npm dist-tags: `latest`, then `next` to the same version

## Scope

Version `0.5.0` adds bounded GAL search and recurring Calendar create, update,
delete, cancel, and response flows. It preserves the 22 existing MCP tools and
adds `people_search`, for a total of 23. Existing one-off event calls and object
references remain compatible.

## Accepted exceptions

The release owner explicitly accepted the following exceptions on 2026-09-01
because there was no remaining time for additional acceptance testing:

- No live EAS read or write was run for this feature candidate.
- Personal recurring create/update/split/delete was not live-tested.
- Recurring invitation delivery, update, cancellation, and participant response
  were not tested with a real recipient.
- Native Windows 11 Credential Manager, corporate TLS/VPN, and mailbox behavior
  were not tested; Wine and Windows CI evidence are accepted as residual risk.
- No physical Intel Mac was available; Rosetta evidence is accepted.
- No new eight-hour soak or third-provider test was run.

These are not passing results. Any post-release failure must be handled in a new
version; ambiguous or partial writes must not be retried with a new UUID.

## Publication gate

Before staging, the release commit must be clean and pass the available local
checks, version synchronization, npm packaging, source/artifact audits, and
arm64 install smoke. Publish all native packages first and the root package last.
After registry smoke, move `next` to `0.5.0` and create source-only tag/release
`v0.5.0`.
