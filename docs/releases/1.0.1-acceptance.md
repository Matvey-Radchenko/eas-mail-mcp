# 1.0.1 release acceptance

- Status: released and verified, 2026-09-07
- Release type: stable calendar bug-fix patch
- Accepted release commit: `67a498d67e9a38792b0446fe584f5c32b17e7ce2`
- Functional source: `62e56c8b7613357a2e6a3fe6cef21650bd2b002a`

## Scope

- Zero-duration events and recurring occurrences no longer break calendar reads.
  Creation and editing retain positive-duration validation.
- Forwarded recurring invitations can be answered through mail references.
  Attendance replies preserve organizer and occurrence identity and do not
  require support for unrelated full-item edit metadata.
- Online meeting attendee updates preserve server-managed connection metadata
  and unchanged exceptions. Roster-only notifications target affected people;
  content or schedule changes reach all current attendees. Unsafe disabled
  exception reminder rewrites fail before mutation.

The MCP/CLI public contract and journal schema are unchanged. Updating does not
require account or password reconfiguration.
